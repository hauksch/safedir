# Audit 2026-10-11 — findings and remediation status

Four independent read-only reviews (ID layer, domain model/matrix, extract/resolver/backends, VAS client/CLI/infra), each cross-checked against the archived specs in `docs/specs/`. Status is updated per remediation phase.

## Verified sound (highlights)

- SAFE-ID checksum: SHA-256 over lowercased body, first two bytes hex — independently recomputed against all golden vectors (`85ed`, `334d`, `39c5`, `b1eb`).
- `lookupRequest` construction matches the standard's §6 example verbatim; `xml_escape` covers request-side attribute/text contexts.
- No XXE/billion-laughs path (quick-xml ignores DTDs; `check_end_names` fails closed on mismatched tags); no `unwrap`s on production paths.
- `SearchQuery::matches` AND/OR semantics, A11 case folding, A2 per-word contains, A14 name degradation, builder minimum lengths (for the v1.5-searchable attributes).
- Extract serde round-trip, `validate()` duplicate/PEM/role checks, `ExtractResolver` immutability, dyn-compatibility of `SafeDirectory`.
- deny.toml license set covers the locked dependency graph; CI deny job viable.
